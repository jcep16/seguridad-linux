# Mecanismo de despliegue

Esta carpeta contendrá la infraestructura para validar y aplicar
configuraciones versionadas en el repositorio.

## Estado actual

La infraestructura está en preparación. No se incluyen todavía
configuraciones de los ejercicios de Seguridad 1.

## Principios

- Validar antes de aplicar.
- Evitar depender de rutas personales.
- Mantener las configuraciones bajo control de versiones.
- Comprobar los resultados después de cada aplicación.
