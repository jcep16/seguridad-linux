# Procedimiento de colaboración con Git

## Rama principal
- main: contiene la versión integrada del proyecto.

## Ramas de trabajo
Cada integrante creará una rama para su tarea.
Ejemplo: feature/configuracion-usuarios.

## Flujo de trabajo
1. Descargar los últimos cambios con git pull.
2. Crear o cambiar a una rama de trabajo.
3. Modificar únicamente los archivos correspondientes.
4. Revisar los cambios con git status y git diff.
5. Registrar los cambios con git add y git commit.
6. Subir la rama con git push.
7. Solicitar una revisión mediante un Pull Request.
8. Integrar los cambios en main después de revisarlos.

## Reglas
- No subir contraseñas, tokens ni claves privadas.
- No sobrescribir cambios ajenos sin revisarlos.
- Utilizar mensajes de commit descriptivos.
- Probar las configuraciones antes de aplicarlas al sistema.
- Documentar los cambios relevantes.
