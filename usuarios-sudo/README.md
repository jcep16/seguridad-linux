# Usuarios, grupos y sudo

Esta sección contiene los scripts y las configuraciones
relacionadas con la administración de usuarios en Linux.

## Perfiles previstos
- Administrador
- Acceso remoto
- Operador de copias de seguridad
- Usuario normal

## Archivos
- comprobar_perfiles.sh: verifica usuarios y grupos existentes.
- configurar_perfiles.sh: se añadirá posteriormente para crear
  los perfiles y configurar sus permisos.

## Seguridad
Las configuraciones deben probarse antes de aplicarse
en el sistema definitivo.
