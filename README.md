# Proyecto Seguridad 1 - Linux

## Objetivo
Configurar y comprobar mecanismos de seguridad en Linux.

## Componentes
- Perfiles de usuarios y sudo
- Usuario restringido (jail)
- AppArmor
- Fail2ban
- ClamAV
- Pruebas de seguridad con Hydra

## Uso
Las configuraciones y scripts se encuentran organizados
por componente. Revisar las instrucciones de cada carpeta
antes de ejecutar cualquier script.
