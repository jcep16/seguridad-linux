# Proyecto Seguridad 1 - Linux

## Objetivo
Configurar y comprobar mecanismos de seguridad en Linux.

## Componentes
- Perfiles de usuarios y sudo
- Usuario restringido (jail)
- AppArmor
- Fail2ban
- ClamAV
- Pruebas de seguridad con Hydra

## Uso
Las configuraciones y scripts se encuentran organizados
por componente. Revisar las instrucciones de cada carpeta
antes de ejecutar cualquier script.

## Estructura
Cada carpeta contiene la documentación y los archivos
correspondientes a un componente.

## Colaboración
Los cambios se gestionan mediante Git y GitHub.
Antes de aplicar cualquier configuración al sistema,
se deben revisar las instrucciones y probar los cambios.

## Seguridad
No subir contraseñas, tokens, claves privadas ni otros secretos.
